# SMART PPE Vision – Pemantauan APD

Prototipe dashboard pemantauan APD (helm, rompi, sepatu safety, sarung tangan) untuk proyek konstruksi.
Fitur: kamera simulasi, zona proyek, peringatan, dan laporan K3 otomatis.

> Data di halaman ini **simulasi** (acak), bukan hasil deteksi kamera nyata.

## Cara menerbitkan lewat GitHub Pages
1. Buat repositori baru di GitHub (mis. `smart-ppe-vision`), set **Public**.
2. Unggah `index.html`, `.nojekyll`, dan `README.md` (Add file → Upload files).
3. Buka **Settings → Pages**. Pada *Build and deployment*, pilih **Deploy from a branch**, branch **main**, folder **/ (root)**, lalu **Save**.
4. Tunggu 1–2 menit. Alamatnya: `https://<username>.github.io/smart-ppe-vision/`

Halaman hanya memakai satu file HTML (font dari Google Fonts), jadi tidak perlu server atau proses build.
